# Shared paraphrase corpus.
#
# Both drafting paths are scored against this same file: the grammar parser in
# :core tests, and the on-device model at the event through the same harness.
# That is the only way "the model is better than the parser" becomes a claim
# with evidence behind it rather than an impression.
#
# Format: one case per line.
#   <input sentence> | <expected semantic assertions, comma separated>
#
# Assertions are deliberately about *meaning*, not about exact JSON: what must
# be preserved is the device, the gate, the effect and the ending. Two drafters
# may legitimately produce different titles for the same cue.
#
# Keys: trigger, device, days, from, to, timer, dnd, endsOnDisconnect,
#       clarify, unsupported
