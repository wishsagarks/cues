## Brand & Style

This design system delivers a deterministic, high-performance operating environment inspired by flagship mobile operating systems and performance-tier devices. It embodies surgical precision, speed, and uncompromising system control for autonomous routines and contextual device automation.

### Personality & Tone
- **Deterministic & Unforgiving:** Zero ambiguity. State changes, active triggers, and automation loops are declared explicitly with zero background inference.
- **Ultra-Mechanical Speed:** Evoking high refresh-rate interfaces, physical relay switches, and instant telemetry feedback.
- **Controlled Aggression:** Deep volcanic black substrates balanced against electric high-voltage accents (Electric Yellow, Monster Orange, and Cyan Frost).

### Target Audience
Power users, systems engineers, and technical device owners who demand verifiable control over smartphone automations, sensor contexts, and reversible system behaviors.

### Design Movement & Aesthetic Style
A synthesis of **Cybernetic Brutalism** and **Tactile Glassmorphism**:
- Ultra-deep, multi-layered obsidian slabs (`#0B0C10` to `#181B26`).
- Laser-sharp 1px structural boundary strokes simulating edge-lit Gorilla Glass.
- High-contrast telemetry tags and clause tokens (`WHEN`, `IF`, `DO`, `UNTIL`, `RESTORE`) set in dense monospace typography.
- Micro-grid engineering backgrounds combined with fluid Origin-style status capsules and interactive dynamic islands.

## Colors

The palette operates in strict dark-field ergonomics, minimizing OLED sub-pixel draw while maximizing contrast for rapid ocular scanning.

### Core Hues
- **Primary — Electric Voltage Yellow (`#FFE600`):** Denotes primary arming states, active cue execution, live routine loops, and dominant call-to-actions.
- **Secondary — Monster Orange (`#FF5E00`):** System overrides, high-risk automation warnings, execution termination, and critical breakpoint markers.
- **Tertiary — Origin Ice Teal (`#00E5FF`):** Deterministic safety verifications, owned & reversible status tags, sensor readouts, and network-isolated tasks.
- **Neutral Base — Volcanic Obsidian (`#0B0C10`, `#12141C`, `#181B26`):** Deep carbon substrate tiers providing rich depth separation without gray-washing.

### Functional Palette Applications
- **Surface Void (`#0B0C10`):** Canvas bedrock and system lock screens.
- **Surface Tier 1 / Slab (`#12141C`):** Root module containers, inactive context cards.
- **Surface Tier 2 / Island (`#181B26`):** Interactive widgets, nested rule blocks, floating action arrays.
- **Telemetry Slate (`#7C8BA1`):** Passive parameters, static clause labels, gridlines, and neutral boundaries.
- **Zero-Inference Green (`#00FF88`):** Verified offline status, air-gapped on-device execution confirmations.
- **Boundary Precision (`rgba(255, 255, 255, 0.08)` to `rgba(255, 230, 0, 0.3)`):** 1px structural hairpins defining glass slab edges.

## Typography

The typographic hierarchy balances razor-sharp machine engineering with mobile screen legibility:

- **Headline Display (`Space Grotesk`):** Industrial, geometric character with technical angles for device parameters, cue names, and system mode banners.
- **Body UI (`Plus Jakarta Sans`):** Clean, open-counter grotesk chosen for comfortable skimming of multi-line parameters and diagnostic descriptions under rapid hand movement.
- **Clause Badges & Technical Telemetry (`JetBrains Mono`):** Fixed-pitch, monospaced density for clause pills (`[WHEN]`, `[IF]`, `[DO]`, `[UNTIL]`, `[RESTORE]`), sensor coordinates, latency readouts, and condition logic statements.

### Text Formatting Directives
- **Monospace Allcaps:** All logic clauses (`WHEN`, `IF`, `DO`, `UNTIL`, `RESTORE`) must be rendered in uppercase JetBrains Mono with `+0.08em` tracking.
- **Numeric Readouts:** Battery percentages, CPU thread allocations, geofence radius values, and execution countdowns must utilize tabular figures (`tnum`) in JetBrains Mono.

## Layout & Spacing

Layouts follow an ergonomic single-hand mobile paradigm optimized for reachability zones along the bottom 60% of the display viewport.

### Grid Architecture
- **Mobile Handset (360px - 480px):** 4-column dynamic grid with a tight `12px` (0.75rem) gutter and `16px` (1rem) margin. Full-width thumb-zone execution trays.
- **Foldable Unfolded / Tablet (481px - 1024px):** 8-column split architecture. The primary canvas pins contextual conditions to the left 4 columns, while active event logs and timeline telemetry map to the right 4 columns.
- **Desktop System Deck (> 1024px):** 12-column fixed grid (maximum content width 1280px) with 24px gutters.

### Spacing Rhythm & Visual Rhythm
- Maintain dense component groupings: routine cards use `space-sm` internal padding between trigger and response blocks to visually bind related logic.
- Independent operational blocks use `space-lg` separation to avoid mistaken tap targets during high-speed device interaction.

## Elevation & Depth

Visual depth is achieved through translucent obsidian plates, frosted refraction, and high-frequency light edges rather than muddy drop shadows.

### Glass Slabs & Backdrop Blurring
- **Base Void (`#0B0C10`):** Solid background with a 16px micro-grid overlay printed at 3% opacity (`#FFFFFF`).
- **Slab Elevation 1:** `background: rgba(18, 20, 28, 0.72)`, `backdrop-filter: blur(24px)`, border: `1px solid rgba(255, 255, 255, 0.07)`.
- **Slab Elevation 2 (Active Widget / Island):** `background: rgba(24, 27, 38, 0.85)`, `backdrop-filter: blur(32px)`, border: `1px solid rgba(255, 230, 0, 0.25)`.
- **Modal / Origin Island Expansion:** `background: rgba(14, 16, 22, 0.95)`, `backdrop-filter: blur(40px)`, border: `1px solid rgba(255, 94, 0, 0.35)`.

### Accent Glow & Neon Halos
- **Active Cue Pulse:** `box-shadow: 0 0 20px rgba(255, 230, 0, 0.18), inset 0 0 1px rgba(255, 230, 0, 0.6)`.
- **High-Risk External Execution:** `box-shadow: 0 0 20px rgba(255, 94, 0, 0.22), inset 0 0 1px rgba(255, 94, 0, 0.7)`.
- **Verified Reversible Glow:** `box-shadow: 0 0 16px rgba(0, 229, 255, 0.15), inset 0 0 1px rgba(0, 229, 255, 0.5)`.

## Shapes

The geometric signature draws from OriginOS fluid capsules combined with iQOO technical edge geometry:

- **Standard Containers & Cards:** `16px` (`rounded-lg`) corner radii for main structural cards, mimicking the curved display corners of flagship smartphones.
- **Nested Context Logic Pills:** `8px` (`rounded-md`) for sub-components, trigger badges, and parameter controls.
- **Dynamic Origin Islands & Status Capsules:** Fully rounded pill shapes (`9999px`) to maintain fluid cohesion during island expansion and collapse.
- **Micro Badges (`[WHEN]`, `[IF]`, `[DO]`): Precise `4px` corner bevels to project a modular, chip-set feel.

## Components

### 1. Monospaced Clause Badges
The non-negotiable anchor elements for routine architecture:
- **`[WHEN]` (Trigger):** Solid Cyan Frost edge (`#00E5FF`) on tinted dark surface (`rgba(0, 229, 255, 0.08)`).
- **`[IF]` (Condition Gate):** Solid Telemetry Slate border (`#7C8BA1`) on neutral glass (`rgba(124, 139, 161, 0.1)`).
- **`[DO]` (Action Execution):** High-voltage Electric Yellow solid fill (`#FFE600`) with jet-black text (`#0B0C10`).
- **`[UNTIL]` (Termination Condition):** High-contrast Monster Orange edge (`#FF5E00`) with matching glow.
- **`[RESTORE]` (State Reversion):** Ghost white border (`rgba(255, 255, 255, 0.4)`) with dotted underline pattern.

### 2. Routine Slab Cards
- **Structure:** Multi-layered slab featuring frosted glass (`rgba(18, 20, 28, 0.75)`), 1px razor perimeter stroke, and an upper status banner.
- **Risk Level Tags:**
  - *Owned & Reversible:* Ice Teal tag with a check-loop icon indicating native settings toggle with auto-rollback.
  - *External Automation:* Amber warning chip denoting third-party webhook or peripheral trigger.
  - *UI Accessibility Automation:* High-alert Monster Orange outline chip indicating direct screen injection and simulated touch.
- **State Indicator:** Upper right zero-inference badge with green pulsed beacon (`#00FF88`) verifying local on-device sensor validation.

### 3. Buttons & Mechanical Triggers
- **Arm / Engage Routine (Primary):** Solid Electric Yellow (`#FFE600`) substrate, Jet Black (`#0B0C10`) typography in `Space Grotesk` Bold. Instant mechanical press down-scale (`0.98`) with zero spring-slop.
- **Emergency Halt / Disarm (Destructive):** Deep obsidian with Monster Orange perimeter (`#FF5E00`), vibrant orange hover glow, and monospaced text.
- **Secondary Parameter Toggle:** Ghost slate with `1px` translucent edge, filling with Ice Teal (`#00E5FF`) when latched.

### 4. Origin Dynamic Islands & Capsules
- **Collapsed Floating Island:** Pill-shaped (`height: 36px`), obsidian backdrop (`#12141C`), containing mini-clause icons (`[WHEN] -> [DO]`), an animated miniature wave monitor, and an elapsed time counter.
- **Expanded Routine Deck:** Animates smoothly downward into an expansive card revealing active condition parameters, live sensor values, and an instant-abort switch.

### 5. Input Fields & Syntax Builders
- **Parameter Inputs:** Monospaced fields set inside deep black recesses (`#0B0C10`) with `1px` crisp borders. Unfocused state uses `#7C8BA1`; focused state lights up with an Electric Yellow glow ring.
- **Inline Threshold Sliders:** High-contrast bar with step-increments marked by 1px vertical tick lines and yellow diamond thumb handles.

### 6. Lists & Log Feeds
- **Execution Telemetry Stream:** Monospaced single-line records with millisecond timestamps, condition evaluation statuses (TRUE / FALSE), and memory footprint indicators, separated by `1px` hairline dividers.

## Brand & Style (Light)

Translates the high-performance, deterministic rigor of motorsport engineering and telemetry dashboards into an ultra-clean, daylight-optimized operational interface. Fuses **High-Precision Glassmorphism** with **Technical Neomorphism and HUD Telemetry** — translucent layers function as structured optic lenses (micro-milled frosted surfaces, ultra-fine 1px perimeter chamfers, crisp mathematical layouts) rather than decorative blur.

## Colors (Light)

High-contrast chromatic accents tuned to exceed WCAG 2.1 AA legibility on bright, layered surfaces:

- **Primary — Telemetry Amber-Gold (`#D97706`):** Critical states, active tracking, focal triggers. Deeper than raw gold for crisp edge definition against white.
- **Secondary — Monster Orange (`#EA580C`):** Aggressive alerts, threshold warnings, active runtime indicators, high-velocity actuators.
- **Tertiary — Cyber Teal (`#0891B2`):** Logic gates, verified operational status, deterministic telemetry paths.
- **Neutral System:**
  - Base Obsidian (`#0F172A`): headlines, core telemetry data, critical values.
  - Deep Slate (`#334155`): secondary copy, field labels, structural metadata.
  - Muted Carbon (`#64748B`): inactive values, micro units, boundary markers.
- **Surfaces & Layers:**
  - Base Daylight Canvas: `#F8F9FD`
  - Elevated Container / HUD Tile: `#FFFFFF`
  - Sub-surface Wells & Track Insets: `#EEF1F8`
  - Structural Borders & Grooves: `#E2E6F0`

## Typography (Light)

Three-tier functional split:
1. **Space Grotesk** — display & headlines, geometric/aerodynamic.
2. **Inter** — interface & body text, metadata, forms (note: light theme uses Inter, not Plus Jakarta Sans).
3. **JetBrains Mono** — deterministic operators & telemetry: numeric values, coordinates, timestamps, and clause syntax `[WHEN]`, `[IF]`, `[DO]`, `[UNTIL]`, `[RESTORE]` — always uppercase, `0.08em`–`0.1em` tracking.

## Elevation & Depth (Light)

No heavy dark drop shadows — depth via diffuse optical glassmorphism, micro-milled outlines, luminous edge highlights:

- **Surface Tier 0 (Canvas Base):** Solid `#F8F9FD`.
- **Surface Tier 1 (Instrument Tile / Rest):** `#FFFFFF` or `rgba(255,255,255,0.85)` + `backdrop-filter: blur(16px)`. Border `1px solid #E2E6F0`. Shadow `0 1px 3px rgba(15,23,42,0.04), 0 6px 16px rgba(15,23,42,0.02)`.
- **Surface Tier 2 (Floating Panel / Actuator Focus):** `#FFFFFF`. Border `1px solid #CBD5E1`. Shadow `0 4px 12px rgba(15,23,42,0.06), 0 16px 32px rgba(15,23,42,0.03)`. Top-edge highlight `inset 0 1px 0 rgba(255,255,255,1)`.
- **Surface Tier 3 (Transient HUD / Popover):** `rgba(255,255,255,0.94)` + `backdrop-filter: blur(24px)`. Border `1px solid #94A3B8`. Shadow `0 12px 28px rgba(15,23,42,0.08), 0 24px 48px rgba(15,23,42,0.04)`.
- **Structural Inset (Wells / Input Backings):** Solid `#EEF1F8`. Border `1px solid #E2E6F0`. Shadow `inset 0 1px 2px rgba(15,23,42,0.04)`.

## Shapes (Light)

- Standard controls, chips, small cards: `0.5rem` (8px).
- Main modules, dashboard panels, viewport trays: `1rem` (16px).
- Modals, prominent widgets, sheet headers: `1.5rem` (24px).
- Telemetry badges, condition tags, pill toggles: fully circular (`9999px`).
